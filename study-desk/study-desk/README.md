# Study Desk (CPAN 144 – Assignment 1)
A small Next.js app: Home page, a Study Session counter, and a Task list.

## Run
npm install
npm run dev   # open http://localhost:3000

## Structure
- app/ – pages (layout.js, page.js, counter/, tasks/) and globals.css
- components/ – Navbar, FeatureCard, Counter, TodoList, TodoItem
